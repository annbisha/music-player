````md
## Features

- User registration and login
- Track playback controls
- Playlist creation and management
- Track search and sorting
- Volume and playback progress controls
- Automatic track switching
- Local demo data storage
- Responsive interface

## Tech Stack

- React
- JavaScript
- Redux Toolkit
- RTK Query
- React Router
- CSS
- Local Storage

## Project Background

The original version of this project used an external GraphQL API.

Because the original educational server is no longer available, I refactored the application into a standalone demo mode. Authentication, tracks and playlists now work locally, allowing the application to remain fully accessible for portfolio review.

## Run Locally

```bash
git clone https://github.com/annbisha/music-player.git
cd music-player
npm install
npm start
```
````

The application will open at:

```text
http://localhost:3000
```
